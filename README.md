## Source for MRU-prereqer

See it live at https://cfcurtis.github.io/mru-prereqer/?course=MATH2234.

I wanted to visualize prerequisite chains for MRU's School of Computing Sciences and Mathematics courses. I would love to use it as an excuse to learn about Javascript and D3.js, but instead, I ended up using CoPilot.

Other than a couple of tweaks to CSS, I did not write this code. I don't understand it. I would not contribute it to an open source project, and I didn't learn anything in writing it. I did manage to make CoPilot really confused and start babbling about [skin allergies](https://github.com/cfcurtis/mru-prereqer/blob/main/copilot_transcript.md#reasoning-130) at one point, which it completely [denied](https://github.com/cfcurtis/mru-prereqer/blob/main/copilot_transcript.md#copilot-185), so that was kind of entertaining.

Anyways, this might be useful, or I might have just burned 960 AI credits worth of greenhouse gasses for nothing.
